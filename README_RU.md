# AI-помощник по учёбе для Telegram

Бот отвечает на вопросы, объясняет школьные темы, помогает разбирать домашние задания и принимает фотографии заданий.

## Что понадобится

- Telegram-бот, созданный через официального `@BotFather`.
- API-ключ OpenAI с доступом к API и настроенным способом оплаты/лимитами, если они требуются для аккаунта.
- Хостинг или компьютер, на котором бот будет работать постоянно.

## Настройка

1. Создай бота через `@BotFather` командой `/newbot` и скопируй токен.
2. Создай API-ключ в кабинете OpenAI API.
3. Скопируй `.env.example` в файл `.env`.
4. Вставь оба секрета в `.env`. Никому их не пересылай и не загружай `.env` в публичные репозитории.
5. Установи Python 3.11 или новее.
6. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

7. Запусти:

   ```bash
   python bot.py
   ```

8. Открой своего бота в Telegram и отправь `/start`.

## Запуск с телефона

Удобнее всего использовать облачный хостинг с поддержкой Python и постоянного фонового процесса (worker/background service). Загрузи файлы проекта в приватный репозиторий или файловое хранилище хостинга, добавь переменные окружения `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`, затем запусти команду `python bot.py`.

Названия кнопок и меню на хостингах могут отличаться. Для круглосуточной работы нужен тариф/режим, который не останавливает фоновые процессы.

## Важно о безопасности и расходах

- Никогда не публикуй токен Telegram или API-ключ. Если секрет случайно раскрыт, отзови его и создай новый.
- Не вставляй ключи в переписку с ботом или в этот чат.
- API-запросы могут быть платными. Настрой лимиты расходов и следи за использованием.
- История диалога хранится только в оперативной памяти процесса и исчезает после перезапуска. Не отправляй боту личные данные, пароли, документы или конфиденциальную информацию.
- Это учебный помощник: проверяй важные ответы по учебнику и материалам учителя.

## Примечание

Бот использует OpenAI Responses API. Если выбранная модель недоступна в твоём API-аккаунте, укажи в `OPENAI_MODEL` модель, которая доступна в твоём кабинете.
