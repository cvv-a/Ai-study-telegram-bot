# SMART AI — Telegram Mini App (демо)

Это фронтенд мини-приложения. Сейчас он показывает интерфейс и демонстрационный чат; реальная нейросеть ещё не подключена.

## Файлы
- `index.html` — структура страницы
- `style.css` — оформление
- `app.js` — поведение и Telegram Web Apps SDK

## Важно
Не вставляйте Telegram-токен или OpenAI API-ключ в эти файлы. Секреты должны храниться только на сервере в переменных окружения.

## Следующий этап
Разместить эти файлы на HTTPS-хостинге, затем настроить кнопку Menu/Web App у Telegram-бота и подключить безопасный серверный endpoint, который будет обращаться к нейросети.
